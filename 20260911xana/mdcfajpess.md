# 北京科学技术奖再+1，“人民”青年科学家榜上有名

> 更新时间：2026-09-11 (UTC+8)

//  

11月7日上午，2024年度北京市科学技术奖励大会召开。

会上，授予北京大学人民医院青年科学家陈克终“杰出青年中关村奖”。
 

 “杰出青年中关村奖”是北京市人民政府颁发的北京市科学技术奖中重要人物类奖项，旨在奖励在北京市重点发展领域科学研究中取得重要发现，推动相关学科发展，或者在关键核心技术研发中取得创新性突破，推动科技成果转化和产业化，具有重大发展潜力的青年科学家。

**获奖人简介**
 
**陈克终**

****

北京大学人民医院胸外科主任医师、胸部肿瘤研究所副所长（主持工作），国自然青年科学基金(A类)（原杰青）、国家万人计划青年拔尖人才获得者，肺癌大数据创新应用北京市重点实验室副主任，北京大学博雅特聘教授，中组部第十批援藏干部。

主要从事胸部疾病的外科诊疗，聚焦肺癌开展基础与临床转化研究。开发肺癌术后无创监测新方法，突破了可手术肺癌复发预警不及时的难题；开发了智能化肺癌管理策略，有效提升分类诊断准确性；揭示了磨玻璃肺癌免疫平衡机制，创建空间疗效预测模型，在国内外学术界产生了重要影响。担任国家科技重大专项首席青年科学家，主持国家自然科学基金委原创探索等重要科研项目。获中国抗癌协会青年科学家奖、北京青年五四奖章等。
 
同时，医院作为第三完成单位，王辉教授作为第三完成人的项目“病毒性肺炎诊疗关键技术创建与推广应用”获得北京市科技奖一等奖。
 

近年来，北京大学人民医院全面落实党和国家关于科技创新工作的决策部署，聚焦临床需求开展源头创新、自主创新和成果转化，强化创新地位和创新能力。并通过实施学科人才战略，发掘、培养和举荐青年人才，重点扶持具有科研领军才能和团队组织管理能力的优秀学术骨干，鼓励医院青年科研人员在各自研究领域勇于进取，积极创新；科研处开设科技奖励申报服务门诊，为奖励申报提供系列服务。

下一步，医院将继续坚持以科学价值和临床价值为导向，落实学科人才战略，不断加大科技研发投入，完善创新转化生态建设，促进学科交叉融合，构建全链条医学科技创新支撑保障体系，在全面高质量发展的道路之上不断向前。
